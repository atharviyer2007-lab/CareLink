How to use CareLink

  • Dashboard — open journeys, overdue/blocked alerts
  • Care Passport — 6 stages; mark done or verify
  • Messages — chat threads + quick replies
  • Calendar & Book — book appointment → email confirmation
  • Report upload — on Care Passport, attach PDF/image to Report stage
  • Reminders — automatic email for appointments today/tomorrow
  • Verify Desk — ASHA / provider verification actions
  • Role (top right) — switch Patient / Caregiver / Doctor / ASHA
  • Reset — restore demo patients and journeys

Email setup (so patients get mail)

  1. Enable 2-Step Verification on your Google account
  2. Create an App Password: myaccount.google.com/apppasswords
  3. Create a file named .env next to app.py with:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=yourname@gmail.com
SMTP_PASSWORD=your_16_char_app_password
SMTP_FROM=yourname@gmail.com
SMTP_TLS=true
PORT=5000

Restart the app (py app.py). Status should show Email: Live.
